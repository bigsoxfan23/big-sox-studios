## A home lab that became a platform

What began as a dedicated personal server grew into a place to learn self-hosting, containers, media services, monitoring, backups, remote administration, and AI-assisted operations.

The useful part is not the number of services. It is having a real environment where reliability, maintenance, and recovery actually matter.

## What lives here

The lab supports a mix of personal media, game-server experiments, monitoring, backup workflows, and the private infrastructure behind several Big Sox Studios AI projects.

This public case study intentionally leaves out addresses, endpoints, credentials, network topology, administrative interfaces, and other details that belong inside the private environment.

## Always evolving

The home lab is never really finished. New projects create new requirements, and each change is a chance to improve the platform without unnecessarily replacing things that already work.
